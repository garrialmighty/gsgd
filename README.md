# GSGD

### Description
GSGD is a SGD-backed stablecoin maintaining a 1:1 redemption value with the Singapore dollar.

### Stability
GSGD is anchored or pegged to the Singapore Dollar (SGD).
Exchange rates are evaluated using an Oracle network (ChainLink).

### Stability Mechanism
User can only mint the stablecoin with enough collateral.

### Collateral
Accepted crypto currencies include:
- ETH
- BTC
